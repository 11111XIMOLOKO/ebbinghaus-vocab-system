# v2：人机协作精修版

## 开发方式

和 v1 基于同一套 SDD 文档（人主导设计，AI 辅助产出）。唯一变量是**开发过程中人有没有参与迭代**。

工作流：AI 写代码 → 人测 → 人反馈 → AI 改 → 循环。每项 Task 不是"写完就过"，而是"测过才算完"。

## v1 → v2 改进记录

### Bug 修复（14 项）

- 登录失败（Vite 代理端口错误）
- 8088 端口被占导致启动失败
- JwtInterceptor 空 token 返回 500 而非 401
- 全局异常处理不设 HTTP 状态码
- 普通用户可访问后台（路由守卫缺角色检查）
- 侧边栏缺少「学习计划」入口
- 词库选择后 Study 页仍显示「词库已学完」
- 换词库流程绕路
- 统计饼图显示逐个单词（应为分类聚合）
- 折线图 Y 轴小数值刻度、图例与标签重叠、右 Y 轴无意义
- 分页查询报错（缺 MybatisPlusConfig）
- 词库只有 159 个示例词
- 「今日打卡」按钮跳错页面
- 退出登录按钮位置不明显

### 体验优化（11 项）

- 全局设计系统移植（CSS 变量 + Element Plus 组件覆盖）
- 侧边栏 + 顶栏统一布局，各页面去独立 header
- 登录/注册页改为暖灰风格
- Statistics 饼图过滤空阶段、改为环形饼图
- Statistics 折线图改为混搭图表 + 时间维度切换 + KPI 仪表盘
- 复习反馈统一用 ElMessage 弹窗
- 艾宾浩斯轮次标签 + 间隔变化提示
- 学习完成后引导去复习刚学的词
- 浏览器图标改深灰底 + 标题改为系统名
- 饼图改为按词库分类聚合
- Dashboard 页面卡片风格升级

### 数据

- 词库从 159 个示例词扩充到 **54,356 个真实词**（初中/高中/四级/六级/考研/托福/SAT）

### 工作流沉淀

- 每个 Task 前交代「新增功能 / 怎么测试 / 理想效果」，写入 CLAUDE.md
- 测试分「接口级（AI 自测）」和「体验级（需人工）」两层
- 测试说明写清楚目录和命令
- 数据库操作偏好、UI 风格改造列为正式 Task
- Tasks 新增「阶段九：界面风格统一」（T-UI-1~5），总计 60 项

## 快速开始

**环境要求：** JDK 17+ / Maven 3.6+ / Node.js 18+ / MySQL 8.0+

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS ebbinghaus_vocab"

# 2. 启动后端（端口 8082）
cd server && mvn spring-boot:run

# 3. 启动前端（端口 5173，被占会自动选 5174）
cd client && npm install && npm run dev
```

浏览器打开 `http://localhost:5173`（或 5174），账号 `admin` / `admin123`。

> 和 v1 使用不同端口，两个版本可以同时运行对比。
