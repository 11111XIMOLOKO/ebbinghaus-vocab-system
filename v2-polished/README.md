# v2：人机协作精修版

## 开发方式

和 v1 拿到的是完全相同的 SDD 文档。唯一区别：**人在每一轮迭代里都参与了。**

工作流：AI 写代码 → 人测 → 人反馈 → AI 改 → 循环。每项 Task 不是"写完就过"，而是"测过才算完"。

## v1 → v2 改进记录

### Bug 修复（9 项）

- 登录失败（Vite 代理端口错误）
- JwtInterceptor 空 token 返回 500
- 全局异常处理缺少 HTTP 状态码
- 普通用户可访问后台（路由守卫缺角色检查）
- 侧边栏缺少「学习计划」入口
- 词库选择后需多跳一步到学习计划页
- 换词库后仍显示「词库已学完」
- 统计饼图/折线图数据异常
- 分页查询报错（缺 MybatisPlusConfig 分页插件）

### 体验优化（9 项）

- 全局设计系统统一（侧边栏 + 顶栏布局，暖灰配色）
- 登录/注册页风格优化
- 饼图过滤空阶段
- 折线图改为混搭图表 + 时间维度切换 + KPI 仪表盘
- 复习反馈统一用 ElMessage 提示
- 艾宾浩斯轮次标签 + 复习间隔说明
- 学习完成后引导去复习刚学的词
- 浏览器图标和标题
- 各页面 header 统一到 App.vue

### 数据

- 词库从 159 个示例词扩充到 **54,356 个真实词**（初中/高中/四级/六级/考研/托福/SAT）

### 工作流沉淀

- Tasks 新增「阶段九：界面风格统一」5 个 UI 任务
- 工作方式写入 CLAUDE.md：每个 Task 前交代功能/测试方法/理想效果，测试分接口级（AI 测）和体验级（人测）

---

v1 和 v2 基于完全相同的 Specs + Design。结果的区别来自每一轮迭代中人的判断。
