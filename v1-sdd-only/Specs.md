# Specs — 系统功能规格

> 本文档描述艾宾浩斯单词背诵学习系统**做了什么**。Design.md 描述**怎么做的**。

---

## 1. 系统概述

基于艾宾浩斯遗忘曲线的自适应词汇学习系统。用户注册后可选词库、学新词、提交熟悉度，系统自动计算下次复习时间。管理员可通过后台维护词库、用户和公告。

- **用户角色：** 普通用户 + 管理员
- **系统形态：** 浏览器访问的 Web 应用，用户数据持久保存
- **登录有效期：** 24 小时无操作后需重新登录
- **词库学习：** 同一时间只能学习一个词库，切换后新词库从头开始
- **管理员账号：** 系统首次启动时自动创建（admin / admin123）

---

## 2. 核心功能（详细描述）

**主入口：** 用户登录后进入首页，看到今日任务面板（待学习新词数 + 待复习词数）、系统公告轮播、连续打卡天数、累计掌握单词数。点击"开始学习"进入学新词流程，点击"开始复习"进入复习流程。

### 2.1 用户认证

| 功能 | 验收标准 |
|---|---|
| **注册** | 用户输入用户名 + 密码 → 系统校验用户名唯一性 → 返回注册成功 |
| **登录** | 用户输入用户名 + 密码 → 系统验证 → 返回登录凭证。凭证 24 小时后失效，需重新登录 |
| **登出** | 用户主动登出 → 凭证失效 → 后续请求无法通过认证 |
| **认证拦截** | 未登录用户访问需要认证的页面或接口 → 拒绝访问 |

### 2.2 学习流程

| 功能 | 验收标准 |
|---|---|
| **选词库** | 用户从可用词库中选择一个开始学习。具体词库列表见 §3.1 |
| **学新词** | 系统从当前词库中随机抽取未学过的词（数量由学习计划配置，见 §3.3） → 展示英文 + 中文释义 → 用户确认"认识"或"不认识" → 认识的词排入复习计划（初始阶段 = 0，首次复习 = 5 分钟后）。不认识的词同样排入复习计划（阶段 = 0，标记为不认识）学过的词统一管理，后续复习时从复习队列中按到期时间出现 |
### 2.3 复习算法（核心）

> 学习阶段完成后，单词进入复习周期。复习阶段的判断选项从二选一（认识/不认识）扩展为三选一（认识/模糊/不认识）——复习阶段需要更精确地衡量记忆程度。

**八阶段递进式复习。** 每完成一轮复习，系统根据结果更新复习轮次和下次复习时间。阶段从 0 开始计数，阶段 7 为已掌握。

| 阶段 | 间隔 | 说明 |
|---|---|---|
| 阶段 0 | 5 分钟 | 首次学习后短时复习 |
| 阶段 1 | 30 分钟 | 第二次强化 |
| 阶段 2 | 12 小时 | 当天内巩固 |
| 阶段 3 | 1 天 | 隔天复习 |
| 阶段 4 | 2 天 | 间隔拉长 |
| 阶段 5 | 4 天 | 进入长期记忆 |
| 阶段 6 | 7 天 | 每周巩固 |
| 阶段 7 | 15 天 | 到达此阶段即视为已掌握 |

| 复习结果 | 系统行为 |
|---|---|
| **认识** | stage += 1（最多到 7）。到达阶段 7 且最近一次结果为认识 → 标记为"已掌握" |
| **模糊** | stage -= 1（不低于 0）。按回退后的阶段计算下一次复习时间 |
| **不认识** | stage 重置为 0，从头开始复习周期 |

**验收：** 用户每复习一个词 → 系统根据熟悉度调整该词的复习阶段，计算下次复习时间，并记录本次复习结果。

**边界说明：**
- UI 始终显示三按钮（认识/模糊/不认识）。首次复习时点"模糊"和"不认识"效果相同——都视为未掌握，5 分钟后重新出现
- 最高阶段点"认识"：该词标记为已掌握，后续不再出现在复习队列。通过错词本重新学习可重新进入复习周期
- 短间隔复习（5 分钟/30 分钟）：词条到期后进入复习队列，用户下次打开页面时可见
- 复习到期的词按到期时间先后展示，全部展示不设上限

## 3. 外围功能（简要描述）

### 3.1 词库管理

用户可浏览 7 个公共词库（初中/高中/四级/六级/考研/托福/SAT），每个词库包含英文单词 + 中文释义。管理员可在后台增删改词库和单词。

| 功能 | 验收标准 |
|---|---|
| 浏览词库 | 用户进入词库页面 → 看到全部可用词库列表，每个词库显示名称和单词数量 |
| 开始学习 | 用户选择一个词库 → 该词库设为当前学习词库，后续"学新词"从中抽取 |

### 3.2 错词本

用户在学习或复习中标记为"不认识"或"模糊"的单词自动归入错词本。用户可查看错词列表，选择重新学习——重新学习按复习流程走（三选一：认识/模糊/不认识），从头开始复习周期。

| 功能 | 验收标准 |
|---|---|
| 查看错词 | 用户进入错词本 → 看到所有错词列表（单词、错误次数、来源） |
| 重新学习 | 用户选择错词 → 进入复习流程 → 提交结果后该词从错词本移除 |

### 3.3 学习计划与目标

用户可设置每日学习新词数（默认 10 个）和复习倍数（默认 1 倍）。今日任务面板显示的建议复习数 = 新词数 × 复习倍数。实际开始复习时，所有到期词均会出现——建议数仅作为当日目标展示，不限制实际可复习的数量。

| 功能 | 验收标准 |
|---|---|
| 查看计划 | 用户进入学习计划页面 → 看到当前新词数、复习倍数设置 |
| 修改计划 | 用户修改新词数或复习倍数 → 保存后今日任务面板数字按新设置刷新 |

### 3.4 打卡统计

用户在打卡页面手动签到。当日首次签到后系统标记为已签到。连续打卡天数从今天往前逐天检查——中间有一天未打卡即断签，从最近一次连续的第一天重新计数。统计面板展示：累计学习天数、连续打卡天数、每日学习词数趋势图、各轮次词数分布。

| 功能 | 验收标准 |
|---|---|
| 签到 | 用户当日首次签到 → 系统记录签到日期 → 连续天数更新。再次签到提示"今日已签到" |
| 查看统计 | 用户进入统计页 → 看到累计天数、连续天数、趋势折线图、各阶段饼图 |

### 3.5 后台管理

管理员功能：用户管理（查看/禁用/删除）、词库与单词维护、公告发布、操作日志查看。普通用户不可访问后台。

| 功能 | 验收标准 |
|---|---|
| 用户管理 | 管理员查看所有用户列表 → 可禁用/解禁/删除任一用户 |
| 词库维护 | 管理员创建/编辑/删除词库，在词库中增删单词 |
| 公告发布 | 管理员创建公告（标题+内容+类型），用户端首页可见 |
| 操作日志 | 系统自动记录管理员增删改操作（谁、在哪个模块、做了什么、什么时候） |

## 4. 边界场景处理

| 场景 | 系统行为 |
|---|---|
| 词库全部学完 | "开始学习"时提示"当前词库已全部学完"，建议换词库 |
| 复习队列为空 | "开始复习"时提示"今日暂无待复习单词" |
| 当日已签到 | 再次点击签到提示"今日已签到" |
| 未选词库时开始学习 | 提示"请先选择词库" |
| 学习途中换词库 | 原词库的学习进度保留，新词库从头开始 |
| 同一词反复不认识 | 连续多次被标记为"不认识"的词会一直停留在复习计划的低阶段。V1 无兜底策略，后续版本可加入待攻克标记 |

## 5. 功能范围边界

- ❌ 移动端 App
- ❌ 语音播放单词发音
- ❌ 社交功能（排行榜、好友对战）
- ❌ 第三方登录（微信/GitHub）
- ❌ 忘记密码/重置密码
- ❌ 修改密码
- ❌ 多设备同时登录（后登录的设备会使前一设备凭证失效）
- ❌ 单词图片/例句展示
