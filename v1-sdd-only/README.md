# v1：纯 SDD 生成版

## 开发方式

AI 拿到 SDD 文档（Specs + Design + Tasks + CLAUDE.md），独立完成所有代码。**人在这个版本里没有碰代码。**

AI 的行为：
- 按 Tasks 顺序逐个实现
- 每完成一个 Task 标记为完成
- Specs 的验收标准都通过了——功能都在

## 结果

功能正确——注册、登录、背单词、复习、统计，全部能跑。

但体验粗糙——按钮没有颜色区分、列表没有选中状态、交互反馈弱。

这不是 Specs 没写好。是体验细节没办法写成验收标准。

## 与 v2 的关系

v1 和 v2 基于完全相同的 SDD 文档，唯一的变量是开发过程中**有没有人的参与**。

详见仓库根目录的 README。
