## 实验设计

| | v1（`v1-sdd-only/`） | v2（`v2-polished/`） |
|---|---|---|
| **开发方式** | AI 按文档独立完成，人不碰代码 | AI 写 → 人测 → 人反馈 → AI 改 → 循环 |
